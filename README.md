# ContributeNow

> A beginner-friendly frontend app to help new developers start their open-source contribution journey.

ContributeNow is a React + Vite + Tailwind CSS project that provides guidance and resources for developers who want to get started with contributing to open-source software. It’s a learning-oriented tool designed to simplify the first steps into open-source contribution. :contentReference[oaicite:1]{index=1}



## 🌐 Live Demo

👉 https://contribute-now.vercel.app/  
(Live hosted on Vercel — check out the user interface and features.)



## 📦 What This Project Is

- A **React** application powered by **Vite** for fast development and hot reloading. :contentReference[oaicite:2]{index=2}  
- Styled using **Tailwind CSS** for utility-first design. :contentReference[oaicite:3]{index=3}  
- A tool that provides a starting point and encouragement for developers entering the open-source world. :contentReference[oaicite:4]{index=4}

> This is not a full product or backend-powered app — it’s a **frontend learning tool** and reference starter. :contentReference[oaicite:5]{index=5}


## 🧱 Tech Stack

- **React** — Core UI library  
- **Vite** — Fast build and dev tooling  
- **Tailwind CSS** — Utility CSS framework  
- **JavaScript** — Project language
